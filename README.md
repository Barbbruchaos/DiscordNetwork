# Zapret Discord YouTube для Windows

Набор BAT-скриптов, конфигураций и компонентов `zapret` для работы с ограничениями сетевого доступа к Discord и YouTube в Windows. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

Проект основан на [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и использует материалы оригинальных проектов [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle) и [zapret](https://github.com/bol-van/zapret). Указанная версия публикуемых файлов — [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2).

## Быстрый старт

1. Откройте страницу [релиза 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив.
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»** и примените изменения. При распаковке через 7-Zip или PeaZip этот шаг обычно можно пропустить.
3. Распакуйте архив в каталог без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Для ручной проверки запустите от имени администратора один из файлов `general*.bat`, начиная с подходящей стратегии.
5. Проверьте Discord и YouTube. Если выбранная стратегия не помогает, завершите её работу и протестируйте другой вариант.
6. После выбора стратегии при необходимости откройте `service.bat` и используйте **Install Service** для работы через службу Windows.

Не запускайте одновременно несколько конфигураций. Для остановки ручного запуска закройте соответствующее окно или используйте функции управления в `service.bat`.

## Требования и ограничения

- Windows с правами администратора для запуска стратегий, установки службы и изменения системных параметров.
- В составе используется **WinDivert** — системный компонент для перехвата и обработки сетевого трафика.
- Некоторые защитные программы могут помечать WinDivert как потенциально нежелательный компонент или `Not-a-virus:RiskTool.Multi.WinDivert`. Такая классификация сама по себе не подтверждает наличие вредоносного кода.
- Проверяйте происхождение архива и используйте актуальное защитное ПО. Не отключайте защиту и не добавляйте неизвестные файлы в исключения.
- Сетевые условия различаются, поэтому стратегия, работающая в одной сети, может не подойти в другой.

Подробности о проверках WinDivert приведены в [документации zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

## Настройка DNS

Для отдельных ресурсов может потребоваться **Безопасный DNS / DNS over HTTPS**:

- **Chrome:** в настройках безопасного DNS выберите конкретного поставщика вместо варианта по умолчанию.
- **Firefox:** в настройках DNS через HTTPS выберите ручного поставщика, например `https://dns.google/dns-query`.
- **Windows 11:** Secure DNS можно включить в системных настройках.
- **Keenetic:** проверьте параметр **«Транзит запросов»**. Его отключение может мешать работе Secure DNS на компьютере.

## Ручной запуск стратегий

`general*.bat` предназначены для ручного запуска стратегий. В каталоге могут присутствовать варианты `ALT`, `FAKE`, `SIMPLE FAKE`, `EXP` и другие конфигурации. Выбирайте стратегию по инструкции проекта и тестируйте варианты последовательно.

При обычном запуске должен появиться процесс `winws.exe`. Ручной запуск действует только пока работает запущенная конфигурация и не устанавливает её в автозапуск Windows.

## Работа через службу

`service.bat` предназначен для управления службой и диагностики. Доступные пункты зависят от опубликованной конфигурации проекта:

- **Install Service** — добавляет выбранную стратегию в автозапуск Windows.
- **Remove Services** — удаляет созданные службы и WinDivert.
- **Check Status** — показывает состояние служб и активной конфигурации.
- **Game Filter** — управляет обработкой игрового трафика через UDP/TCP на соответствующих портах.
- **IPSet Filter** — включает или отключает фильтрацию адресов из `ipset-all.txt`.
- **Auto-Update Check** и **Check for Updates** — проверяют доступность обновлений.
- **Replace active fakes** — меняет используемый fake-файл на вариант из `bin`.
- **Update IPSet List** — обновляет `ipset-all.txt`.
- **Update Hosts File** — обновляет hosts для отдельных Telegram-ресурсов и голосовых подключений Discord.
- **Run Diagnostics** — ищет распространённые причины неправильной работы.
- **Run Tests** — запускает тесты доступных стратегий.

Запускайте `service.bat` от имени администратора. После изменения параметров может потребоваться повторный запуск активной стратегии.

## Фильтры и тесты

### IPSet Filter

Режим может иметь следующие состояния:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

Режим `ipset any` может затрагивать соединения, которые не должны обрабатываться, поэтому не используйте его постоянно без необходимости.

### Run Tests

- **Standard tests** проверяет ресурсы из `utils/targets.txt`.
- **DPI checkers** выполняет дополнительные проверки DPI для различных сетевых условий.

## Устранение проблем

### После запуска `general*.bat` ничего не происходит

Проверьте запуск от имени администратора, попробуйте другую стратегию и выполните `service.bat` → **Run Diagnostics**. При запуске стратегии должен появиться процесс `winws.exe`. Дополнительное обсуждение: [#522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **Update Hosts File**. Если программа предлагает изменить hosts вручную, скопируйте предложенное содержимое, откройте файл `hosts` с правами администратора, добавьте строки и сохраните изменения.

### Discord не подключается

Проверьте Secure DNS, запустите `service.bat` → **Run Diagnostics`, очистите кэш Discord и протестируйте другую стратегию. Также проверьте веб-версию: [discord.com/app](https://discord.com/app). Если браузерная версия работает, причина может быть связана с локальными данными приложения. Дополнительное обсуждение: [#252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### YouTube не открывается

Проверьте Secure DNS, протестируйте другую стратегию и убедитесь, что работе не мешает сторонний блокировщик рекламы. Дополнительное обсуждение: [#251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Не работают игры или конфликтует приложение

Через `service.bat` обновите IPSet, проверьте **Game Filter** и **IPSet Filter**, затем протестируйте другую стратегию. Для исключения влияния фильтрации временно установите **Game Filter** в `disabled`, а **IPSet Filter** — в `none`. Дополнительные IP-адреса и подсети можно добавить в `ipset-all.txt`.

### Стратегия перестала работать

Сетевые условия могли измениться. Запустите другую стратегию, выполните **Run Diagnostics**, обновите IPSet и hosts, затем повторите проверку. Описание параметров стратегий находится в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### WinDivert остался в службах после удаления

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Найдите имя службы и выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

Для Windows 7 сведения о версиях WinDivert находятся в разделе [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7). Информация о специальной конфигурации WinDivert доступна в разделе [`windivert-hide`](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

## Пользовательские списки

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`:

- `list-general-user.txt` — пользовательские домены и поддомены;
- `list-exclude-user.txt` — домены, которые нужно исключить;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

## Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → **Remove Services**.
4. Выполните **Run Diagnostics**.
5. Удалите старую папку проекта.
6. Скачайте архив из [Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив через свойства Windows.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general`-стратегий.
10. После выбора подходящей конфигурации используйте **Install Service**, если нужна работа через службу.
