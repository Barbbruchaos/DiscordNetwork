# zapret Discord YouTube для Windows

Набор BAT-скриптов, конфигураций и компонентов zapret для работы с ограничениями сетевого доступа к Discord и YouTube в Windows. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

## Быстрый старт

1. Откройте страницу релиза [zapret 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив.
2. Если в свойствах архива Windows доступен пункт **«Разблокировать»**, установите флажок и примените изменения. При использовании 7-Zip или PeaZip этот шаг обычно можно пропустить.
3. Распакуйте архив в каталог без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Откройте распакованную папку от имени администратора.
5. Для ручного запуска запустите подходящий файл `general*.bat`, например `general.bat`.
6. Проверьте работу Discord и YouTube. Если выбранная стратегия не помогает, остановите её и последовательно протестируйте другие доступные варианты.

Перед запуском проверьте происхождение архива. Не используйте файлы из неизвестных источников.

## Настройка DNS

Для отдельных ресурсов может потребоваться **Безопасный DNS / DNS over HTTPS**.

- В Chrome откройте настройки безопасного DNS и выберите конкретного поставщика вместо варианта по умолчанию.
- В Firefox откройте настройки DNS через HTTPS, выберите ручного поставщика и укажите адрес, например `https://dns.google/dns-query`.
- В Windows 11 Secure DNS настраивается в системных параметрах.
- На роутерах Keenetic проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

## Запуск стратегий

### Ручной запуск

`general*.bat` предназначены для ручного запуска стратегий. Точное имя нужного файла зависит от опубликованного набора конфигураций. Разные сети и провайдеры могут обрабатывать соединения по-разному, поэтому протестируйте несколько доступных вариантов, включая стратегии с обозначениями `ALT`, `FAKE`, `SIMPLE FAKE` и `EXP`, если они присутствуют в распакованной папке.

При обычном запуске стратегии должен появиться процесс `winws.exe`. Для запуска BAT-файлов и диагностики используйте командную строку или файл от имени администратора.

### Работа через службу Windows

`service.bat` используется отдельно от ручного запуска и предоставляет пункты управления службой и конфигурацией, включая:

- **`Install Service`** — добавление выбранной стратегии в автозапуск Windows;
- **`Remove Services`** — удаление созданных служб и WinDivert;
- **`Check Status`** — проверка состояния служб и активной конфигурации;
- **`Run Diagnostics`** — диагностика распространённых причин неправильной работы;
- **`Run Tests`** — проверка доступных стратегий;
- **`Game Filter`** — управление обработкой игрового трафика;
- **`IPSet Filter`** — настройка фильтрации адресов из `ipset-all.txt`;
- **`Update IPSet List`** — обновление `ipset-all.txt`;
- **`Update Hosts File`** — обновление hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- **`Replace active fakes`** — выбор другого fake-файла из каталога `bin`.

Сначала протестируйте стратегии вручную. После выбора подходящей конфигурации при необходимости используйте `service.bat` → **`Install Service`**. Не запускайте одновременно несколько стратегий.

## Фильтры и пользовательские списки

`IPSet Filter` может иметь следующие состояния:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — используются адреса из загруженного списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` может затрагивать соединения, которые не должны обрабатываться, поэтому не используйте его постоянно без необходимости.

Пользовательские ресурсы можно добавлять в следующие файлы:

- `list-general-user.txt` — домены и поддомены;
- `list-exclude-user.txt` — домены-исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске zapret или `service.bat`.

## Проверка стратегий

Пункт **`Run Tests`** включает:

- **Standard tests** — проверку ресурсов из `utils/targets.txt`;
- **DPI checkers** — дополнительные проверки DPI для разных сетевых условий.

## Устранение проблем

### `general*.bat` не запускает стратегию

Проверьте наличие процесса `winws.exe` и выполните следующие действия:

1. Запустите BAT-файл от имени администратора.
2. Остановите текущую стратегию и попробуйте другую.
3. Откройте `service.bat` → **`Run Diagnostics`**.
4. Сверьте ситуацию с обсуждением [#522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **`Update Hosts File`**. Если скрипт предложит изменить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки;
4. сохраните файл и повторите проверку подключения.

### Не подключается Discord

Проверьте Secure DNS, запустите **`Run Diagnostics`**, очистите кэш Discord и протестируйте Discord в браузере по адресу [discord.com/app](https://discord.com/app). Если браузерная версия работает, причина может быть связана с локальными данными приложения. Дополнительная информация приведена в [обсуждении #252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### Не открывается YouTube

Проверьте настройку Secure DNS, попробуйте другую стратегию и временно исключите влияние стороннего блокировщика рекламы. Дополнительные варианты обсуждаются в [#251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Не работают игры или конфликтует приложение

Игры используют разные сетевые схемы, поэтому одна конфигурация подходит не всегда. В `service.bat` проверьте **`Game Filter`** и **`IPSet Filter`**, обновите IPSet и протестируйте другие стратегии. Чтобы исключить влияние фильтрации, временно установите `Game Filter` в `disabled`, а `IPSet Filter` — в `none`.

Для проблем с конкретной игрой используйте [Discussions](https://github.com/Flowseal/zapret-discord-youtube/discussions).

### Стратегия перестала работать

Сетевые условия могут измениться. Попробуйте другую стратегию, запустите **`Run Diagnostics`**, обновите IPSet или hosts и повторите проверку. Описание параметров стратегий доступно в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → **`Remove Services`**.
4. Запустите **`Run Diagnostics`**.
5. Удалите старую папку проекта.
6. Скачайте архив из раздела [Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив через его свойства.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general`-стратегий.
10. После выбора конфигурации при необходимости используйте **`Install Service`**.

### WinDivert остался в службах после удаления

В проекте используется WinDivert для перехвата и обработки сетевого трафика. Некоторые защитные программы могут классифицировать его как потенциально нежелательное ПО или инструмент повышенного риска. Это не является автоматическим подтверждением вредоносности файла. Проверяйте источник архива и используйте актуальное защитное ПО; не добавляйте неизвестные файлы в исключения.

Чтобы найти оставшуюся службу, откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Затем остановите и удалите найденную службу:

```cmd
sc stop название_службы
sc delete название_службы
```

Дополнительные сведения о WinDivert приведены в документации [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B). Для Windows 7 сведения о версиях WinDivert находятся в разделе [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7). Специальная конфигурация WinDivert для античитов описана в [windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).
